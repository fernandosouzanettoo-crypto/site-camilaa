# Dra. Camila Egypto — Psiquiatria

Site institucional estático (HTML + CSS + JS puro, sem build). Basta abrir o `index.html`.

## Estrutura

- `index.html` — todo o conteúdo do site (textos do layout aprovado)
- `assets/style.css` — visual, cores do logo (`--marinho: #152a45`, `--bege: #c5ad90`)
- `assets/script.js` — link do WhatsApp, menu do celular e animações
- `assets/img/` — fotos, logo e monograma (versões escura e clara)

## O que falta preencher

- **WhatsApp**: troque o número em `assets/script.js` (`const WHATSAPP`).

## Publicar no GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → escolha a branch e a pasta `/ (root)`.
